# Python Predictors

A collection of interactive Python projects that suggest things based on your mood, preferences, or situation! Each predictor uses machine learning with scikit-learn to provide personalized recommendations in a fun, beginner-friendly way.

## Projects

| Project | Description |
|---|---|
| [Bug Fix Success Predictor](./bug-fix-success-predictor/main.py) | Predicts the likelihood of successfully fixing a bug based on input features. |
| [Skincare Routine Selector](./skincare-routine-selector/main.py) | Recommends a personalized skincare routine based on user preferences and skin type. |
| [Dress Style Recommender](./dress-style-recommender/main.py) | Suggests a dress style based on occasion, mood, and preferences. |
| [Pass or Fail Predictor](./pass-or-fail-predictor/main.py) | Predicts whether a student is likely to pass or fail based on input data. |
| [Student Performance Predictor](./student-performance-predictor/main.py) | Estimates student performance outcomes using scikit-learn models. |
| [Student Success Predictor](./student-success-predictor/main.py) | Predicts overall student success likelihood based on key factors. |
| [Mood-Based Snack Recommender](./mood-based-snack-recommender/main.py) | Recommends a snack based on the user's current mood. |

## Tech Stack

- Python 3
- scikit-learn (machine learning models)

## Getting Started

Each project can be run directly with Python 3:

```bash
cd bug-fix-success-predictor
python3 main.py
```

Install dependencies first if needed:
```bash
pip install scikit-learn
```

## About

This repository is a hands-on exploration of applying basic machine learning (via scikit-learn) to everyday, relatable scenarios — turning simple classification and prediction problems into fun, interactive tools.
